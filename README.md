# ANADHANAM

### Rescue Food. Reduce Waste. Share Hope.

Anadhanam is a cloud-based food donation platform
that connects food donors with NGOs and volunteers.

## Technologies

- Java
- Spring Boot
- Maven
- Git & GitHub
- Jenkins
- Docker
- Terraform
- AWS
- SonarQube
- Trivy

## Project Objective

To reduce food waste by connecting restaurants,
hotels and event organisers with NGOs and volunteers.

## DevOps Implementation

- Continuous Integration
- Continuous Deployment
- Infrastructure as Code
- Containerization
- Automated Testing
- Security Scanning
- Cloud Monitoring
